# Форум о тотализаторах

Копия структуры и оформления форума 1x2.su с пустой базой (без участников) и панелью администратора.

## Что внутри

- **Форум:** категории, разделы, подразделы, разделы-ссылки, темы с префиксами (🎲 🧩 🧤 Профит Мульти), ответы, цитаты, упоминания @ник, реакции (👍 🔥 💯 🎯 🍀 🚀 🏆), BBCode-редактор, закрепление и закрытие тем, поиск, «Что нового».
- **Участники:** регистрация, вход, профиль, аватар, звания по числу сообщений, значки «Команда», «Меценат» и свои.
- **Турниры «Битва прогнозистов»:** матчи, прогнозы П1/Х/П2, таблица, «Зал славы» с медалями. Виджет голосования на главной.
- **Файлы:** каталог программ с категориями, версиями и счётчиком загрузок.
- **Страницы:** правила, помощь, условия, политика конфиденциальности, Инфосервис (открыт с 10 сообщений), обратная связь.
- **Оформление:** светлый, тёмный и системный режим, стили «Новый» и «Старый», адаптивная вёрстка под телефон.
- **Админка (`/admin/`):** статистика (онлайн, посетители, просмотры, регистрации, сообщения по дням, популярные страницы, активные разделы и участники), управление разделами, темами, сообщениями, пользователями (роли, баны, звания, значки, смена пароля), префиксами, файлами, турнирами и матчами, виджетом «Большие победы», текстами страниц, настройками сайта, обратной связью и журнал действий.

## Запуск

Нужен Node.js 22.5 или новее.

```bash
npm install
ADMIN_PASSWORD=придумайте_пароль npm start
```

Сайт откроется на http://localhost:3000. Администратор создаётся при первом запуске:
логин `admin`, пароль из `ADMIN_PASSWORD` (если не задан, случайный пароль печатается в консоли).

Переменные окружения:

| Переменная | Назначение |
|---|---|
| `PORT` | порт, по умолчанию 3000 |
| `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_EMAIL` | первый администратор |
| `DATA_DIR` | где хранить базу и загрузки, по умолчанию `./data` |

Все данные лежат в папке `data/`: база `forum.db` (SQLite) и загруженные файлы. Для резервной копии достаточно скопировать эту папку.

## Размещение на сервере

В папке `deploy/` лежит всё для сервера Ubuntu 22.04 или 24.04: скрипт установки, служба systemd, настройка nginx и ночные резервные копии.

```bash
sudo bash deploy/install.sh ваш-домен.com почта@для-сертификата.ru
```

Скрипт ставит Node.js 22 и nginx, кладёт сайт в `/opt/forum` (данные из `data/` переносятся при первой установке), включает автозапуск, брандмауэр, HTTPS от Let's Encrypt и копии базы в `/var/backups/forum`. Повторный запуск обновляет код, не трогая базу. Пошаговая инструкция с выбором домена и хостинга лежит отдельным документом.

Переменные для сервера (`/etc/forum.env`): `HOST=127.0.0.1` слушать только локально за nginx, `TRUST_PROXY` кому доверять адрес клиента (по умолчанию `loopback`).

## Название и логотип

Название сайта, логотип, цвет шапки, зелёное приветствие для гостей, баннер «Инфосервис», звания, реакции и код счётчика (LiveInternet, Яндекс.Метрика) меняются в админке: **Настройки**. Даты крупных выигрышей задаются в разделе **Большие победы**.
